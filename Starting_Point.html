Getting Started

This class has been designed and created to serve as an introduction to the Linux Operating System, and assist you in learning systems administration techniques in a live environment with real operating systems, instead of the all-too-common simulated environments. The design is simple, multiple operating systems that are logically separated from each other that you can work on.

Who this material is for -- anyone new to Linux, but with a passing knowledge or curiosity in building a career in information technologies. There will be many topics that we seem to skim over or talk past, or if you are already an expert in one area and believe that the material oversimplifies the topic you may be correct. There were attempts made to keep the information relevant, and easily digestible. Material was designed to be an introductory course after all, and too much technical jargon is not fit for our purposes.

System Requirements

To run the labs effectively you will need:

  • A laptop or desktop computer with at least 8GB of RAM (Windows preferably, but Linux/Apple will work)
  • VirtualBox - available for free for personal and educational uses. This is the software that will run our guest VMs. (Accept all installation defaults)
  • Vagrant - this is what imports and configures the guest operating systems and sets up the virtual environment. (Accept all installation defaults)
  • Course Material - this is the book and labs

Environment Setup

VirtualBox

From the above link find the operating system that you will use, download and install. There is a note in the installation about resetting network connections, that is perfectly fine and not a cause for concern.

⚠️ Apple Silicon Mac Users (M1, M2, M3, M4)

If your Mac has an Apple Silicon processor, VirtualBox may not work reliably on your machine. To check your processor, click the Apple menu → About This Mac. If you see "Apple M1", "Apple M2", "Apple M3", or "Apple M4", you have Apple Silicon.

Please contact your instructor before proceeding. Do not spend time troubleshooting VirtualBox on Apple Silicon — alternative virtualization software will be recommended for your machine.

Course Files

This is where the most confusion will occur. Please read over these instructions multiple times before proceeding.

  1. Decide where on your host machine you want to work out of and navigate your command line tool to there:
    • For Windows Users "C:\Users\{YOU}\Documents\IntroToLinux" is recommended
    • For Apple Users "/Users/{YOU}/Documents/IntroToLinux"
    • For Linux Users /home/{YOU}
  2. Use Vagrant to import and set up the environment. Copy the Vagrant file from the Github Repo into your directory, then run the following commands This may take up to 20 minutes to run based on your internet connection and computer device power, be patient!:
    3. 
            vagrant up course-vm
    
            vagrant up server-vm
    
            vagrant up client-vm
  3. Once completed, these virtual machines will now be reachable from your computing device. The button below will take you to the home page of the course
