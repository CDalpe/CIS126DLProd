## Handling Files and Working in Directories

By default Linux stores files and directories in a hierarchical structure. At the top of the structure is called *root* (or *root directory*). Under that exists every file, configuration, application, or hardware handling.

<enter figure showing hierarchical structure>

The first skill we must learn is how to navigate through our environment and how to interact with the landscape. Commands in Linux follow a predictable pattern.

```
command -options
```

Every command is going to have options, and those options greatly alter the behavior of the command. How does Linux know that an administrator wants to change/specify the behavior of their command? The desh (-) afterwards says "using a command, change its behavior in the following ways". Some options are going to be mandatory, how can the OS know what you want to copy/remove/make; some are entirely optional like displaying **ls** in different formats.
